# 应用内更新

入口：自动任务管理 → 更多选项 → 检查更新；工具合集 → 应用更新。

用户手动检查 GitHub 官方 `scorpionfree98/toolkit` 最新正式 Release。只接受已上传的 `toolkit-<version>.apk`、有效 SHA-256、正数且不超过 256 MiB 的资产。版本号按当前发布流程 `0.3.<run_number>` / `1000 + run_number` 比较，未来修改发布版本格式时须同步更新解析器。

下载线路：GitHub 官方（默认）、GHFast、GH-Proxy。后两者是第三方下载代理，不是本项目维护的镜像，不能保证中国境内各运营商均可用。它们只接收公开 APK 地址；最新版本和校验值始终来自 GitHub 官方 API。官方查询失败时明确显示错误，不将镜像数据当作可信版本源。

2026-11-24 本机探测：官方和两条加速线路均能返回 v0.3.16 的校验文件，内容一致。这只证明当时该网络的连通性，不等于各地区可用性承诺。

下载在工作线程执行，可取消，退出页面取消当前工作；不进行静默安装、后台定时检查或任务启动时检查。下载文件写入应用缓存，完成后验证长度、官方 SHA-256、包名、严格递增的 versionCode、versionName、当前安装应用签名。校验失败拒绝安装。FileProvider 仅暴露 updates 缓存目录，系统安装器获得临时读取权限。首次安装需系统允许“安装未知应用”。取消安装后可再次点击安装；重新进入页面可检查并复用已校验的同版本缓存。后续检查自动删除已安装版本的更新缓存。

覆盖升级保留规则和设置，不卸载、不自动导入任何备份，不访问业务链接、CA、捕获日志或用户规则。调试包与正式包签名不一致时拒绝覆盖，不提示用户卸载。

## 验收

- 发布解析：稳定版、按数值比较；草稿/预发布、缺少 APK、错误仓库/URL、缺少校验值、超大资产、未知版本格式均拒绝。
- 当前已是最新版本时禁止下载/安装；网络错误允许重试，下载线路可切换。
- 下载进度、取消、退出、网络中断不改变已安装 App；损坏/截断文件不调用安装器。
- 安装前复核包名、签名、versionCode、摘要；安装授权返回后继续；系统取消可重试。
- 真机完整覆盖更新需存在一个更高版本的正式 APK；本地单测/构建成功不等于已验证系统安装与配置保留。
