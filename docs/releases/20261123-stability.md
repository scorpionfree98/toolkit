# 工具合集：抓包集成与稳定性更新

正式版本号由 GitHub Actions 为本次运行分配。

## 更新内容

- 工具页增加网络抓包入口，包含 HTTP 代理、按应用 VPN IPv4、内置内核、自检、响应修改与日志导出。内核仅支持 Android 10+ ARM64；其他工具保持 Android 8+ 安装兼容性。
- 管理页增加“数据诊断与恢复”：恢复前严格校验、显示差异、保留原始副本，恢复规则默认停用，旧执行队列不重放。
- 后台会话增加容量限制和明确清理入口，保护活动会话与未完成网络恢复；清理失败不报成功。
- 抓包先取得处理名额再构造大数据副本；限制并发、请求体和解压体，过载保持普通响应原样，最终提交继续本地阻断。
- 抓包明确显示启动/运行/停止/恢复待完成状态；旧会话回调不会干扰新会话，清理重试有次数与时间窗口限制。
- 代理关闭时等待监听线程退出，再释放客户端并返回，消除关闭后端口短暂仍可连接的竞态。
- 保留当前模拟定位实现，增加只读诊断；本次不宣称任意第三方应用都会采用模拟位置。

## 验证范围

基础版本离线验证：285 项 JUnit、15 项 Python 检查，Debug/Release 构建、Release Lint 与 APK 运行时资产校验通过。发布检查额外增加监听端口关闭回归（30 次循环），最终 JUnit 总数为 286；最终结果以对应 Actions 运行为准。

签名候选包已完成同签名覆盖安装、配置一致性、恢复预览取消、Shizuku 实际调用、本机 HTTPS 捕获与响应修改、活动会话保护、停止及日志清理检查。独立测试包的 15 项 Android 检查通过，测试包和临时数据已清理。设备自检使用合成流量，不以真实业务操作作为验收。

仍待更广泛的系统故障测试：合集 VPN/DNS/HTTP3、全局 Shizuku 撤权、进程死亡恢复、磁盘故障、长时间峰值内存。IPv6 与 QUIC v2 未实现；未实现自动或定时业务发送。不能把构建或自检通过当作任意目标应用业务成功。

## 升级与隐私

正式 APK 使用既有签名，升级前建议导出规则；不需要卸载或清数据。签名材料与地图 Key 由 Actions Secrets 提供，缺少配置则阻止正式发布。设备日志、业务链接、原始配置和证书私钥不提交仓库。
